# ليلة التحدي — Party Box

لعبة مسابقات عربية تعمل على أربع شاشات: شاشة عرض، وجوال الحكم، وجوال لكل فريق. يمكن اللعب محليًا عبر Wi-Fi بخادم Python، أو عبر الإنترنت باستخدام Supabase Realtime وGitHub Pages.

## اللعب محليًا

ثبّتوا Python 3، ثم شغّلوا `python -m pip install -r requirements.txt` مرة واحدة و`python server.py` عند بدء اللعب. افتحوا عنوان الشبكة الذي يظهر في نافذة الخادم على شاشة العرض، واختاروا «ابدأ الربط». امسحوا رموز QR بالتتابع: الحكم، ثم الفريق الأول، ثم الفريق الثاني. اتركوا نافذة الخادم مفتوحة طوال اللعبة.

للعب على جهاز واحد، افتحوا `index.html` مباشرة في متصفح حديث.

## إعداد اللعب عبر الإنترنت

### 1. إعداد Supabase

1. أنشئوا مشروعًا مجانيًا من [Supabase](https://supabase.com/).
2. من إعدادات المشروع، انسخوا **Project URL** و**Publishable key** (أو مفتاح `anon` العام القديم).
3. ضعوا القيم في `supabase-config.js`:

   ```js
   window.PARTYBOX_SUPABASE = {
     url: "https://YOUR_PROJECT_ID.supabase.co",
     publishableKey: "YOUR_PUBLIC_PUBLISHABLE_KEY"
   };
   ```

   لا تضعوا مفتاح `secret` أو `service_role` في ملفات الموقع. المفتاح العام مخصص للاستخدام في المتصفح.

لا تحتاج اللعبة إلى إنشاء جداول أو سياسات قاعدة بيانات؛ تستخدم Supabase Realtime لبث حالة الجولة وطلبات الجوالات خلال الجلسة. حالة الحكم تحفظ محليًا على جهازه، ولا تُحفظ الجلسات على خادم Supabase بعد انتهاء الاتصال.

### 2. نشر GitHub Pages

1. ارفعوا ملفات المشروع إلى فرع `main` في مستودع GitHub.
2. من **Settings → Pages** اختاروا **GitHub Actions** كمصدر النشر.
3. يشغّل ملف `.github/workflows/pages.yml` النشر تلقائيًا. بعد نجاحه، افتحوا رابط Pages الذي يظهر في ملخص التشغيل.

### 3. بدء جلسة

افتحوا رابط الموقع على شاشة العرض، ثم ابدؤوا الربط وامسحوا رموز QR بالتتابع: الحكم، ثم الفريق الأول، ثم الفريق الثاني. يجب أن يكون لكل الأجهزة اتصال بالإنترنت. أبقوا صفحة الحكم مفتوحة طوال الجلسة؛ أُنشئت روابط الأدوار برموز عشوائية، لذا شاركوا رموز QR مع اللاعبين فقط.

## التحكم والخصوصية

- استخدموا الأزرار أو لوحة المفاتيح؛ اضغطوا `P` للإيقاف المؤقت و`Escape` للاستئناف.
- تحفظ اللعبة حالة الحكم محليًا، وتُزامن النقاط والجولات عبر Realtime.
- في وضع الممثل، تُرسل الكلمة إلى جوال الفريق الذي عليه الدور فقط؛ ولا ترسل الإجابات المخفية إلى شاشات الفرق قبل كشفها.
- يمكن تشغيل المؤثرات الصوتية والتحكم بمستواها من الإعدادات.
- يحتاج اللعب المحلي إلى متطلب QR واحد فقط ولا يحتاج إلى اتصال إنترنت. تحميل مكتبات Supabase وQR من CDN يحدث عند استخدام وضع الإنترنت.
